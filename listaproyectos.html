Lo que he construido y mantengo

Homelab Personal & Infrastructure Tailscale / Jellyfin / Docker / Linux

Diseño, despliegue y administración integral de un servidor doméstico enfocado en privacidad, seguridad y autonomía de datos.

  • Redes y Acceso Seguro: Implementación de una red VPN Mesh con Tailscale para conectividad entre dispositivos remotos sin necesidad de abrir puertos expuestos a Internet (evitando ataques de fuerza bruta).
  • Servicios Multimedia: Despliegue de servidor Jellyfin con transcodificación por hardware para streaming de vídeo continuo a TV, móvil y PC fuera de la red local.
Desarrollo Web Responsive HTML5 / CSS3 / JavaScript Vanilla

Creación y maquetación de proyectos web priorizando el rendimiento nativo, accesibilidad (a11y) y diseño semanticamente limpio.

  • Estructuración Modular: Desarrollo de páginas corporativas, catálogos interactivos y portfolios dinámicos con HTML semántico.
Taller de Sistemas & Hardware Diagnosis / Ensamblaje / Mantenimiento

Servicio técnico especializado en la optimización, mantenimiento preventivo y reparación física/lógica de equipos informáticos.

  • Montaje a Medida: Selección balanceada de componentes según presupuestos específicos, ensamblaje de torres de alto rendimiento y gestión eficiente del cableado (Cable Management).
  • Mantenimiento preventivo/correctivo: Sustitución de pasta térmica, limpieza profunda de disipación, actualización de unidades SSD/RAM y diagnóstico de fallos POST/BIOS.
  • Optimización de Software: Instalación limpia de sistemas operativos, configuración de drivers, eliminación de software dañino y solución de cuellos de botella del sistema.
